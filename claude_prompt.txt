# Claude Code 프롬프트 — 무신사 크롤링 실행 및 MoodFit 연동

아래 프롬프트를 Claude Code에 붙여넣으세요.

---

```
현재 MoodFit 프로젝트에 무신사 크롤링 스크립트가 이미 생성되어 있어. 아래 작업을 순서대로 실행해줘.

## 현재 상태
- scripts/crawl_musinsa.py — 메인 크롤링 스크립트 (이미 생성됨)
- scripts/import_to_moodfit.py — MoodFit 시드 변환 스크립트 (이미 생성됨)
- scripts/requirements.txt — Python 패키지 목록 (이미 생성됨)
- apps/api/ — NestJS 백엔드 (localhost:3001)
- apps/web/ — Next.js 프론트 (localhost:3000)
- 시드 데이터: 테스트 유저 1명 + 옷장 아이템 20개 (이미지 없음)

## 실행할 작업 (순서대로)

### Step 1: Python 패키지 설치
pip install -r scripts/requirements.txt

### Step 2: dry-run 테스트
python scripts/crawl_musinsa.py --dry-run
- 성공하면 Step 3으로
- 실패하면 에러 원인 분석 후 crawl_musinsa.py 수정해서 재실행

### Step 3: 실제 크롤링 실행
python scripts/crawl_musinsa.py
- 카테고리별로 이미지 다운로드
- 무신사가 차단하거나 SPA로 인해 빈 HTML이 오는 경우:
  → pip install playwright && playwright install chromium
  → crawl_musinsa.py의 fetch_ranking_page()를 Playwright 기반으로 수정 후 재실행
- 완료 후 data/images/ 폴더에 이미지가 저장되었는지 확인
- data/metadata.json이 생성되었는지 확인

### Step 4: MoodFit 시드 데이터로 변환
python scripts/import_to_moodfit.py
- data/metadata.json → apps/api/uploads/clothing/ 폴더로 이미지 복사
- data/moodfit_seed_items.json 생성 확인

### Step 5: 시드 서비스에 크롤링 이미지 연동
apps/api/src/seed/seed.service.ts를 수정해서:
- 기존 20개 시드 아이템의 imageUrl에 크롤링된 이미지 경로를 연결
- data/moodfit_seed_items.json 또는 apps/api/uploads/clothing/ 안의 이미지를 참조
- 카테고리별 매칭: top→상의, bottom→하의, outer→아우터, shoes→신발, bag→가방, accessory→액세서리
- imageUrl 형식: /uploads/clothing/{파일명}

### Step 6: Static File Serving 확인
apps/api/src/main.ts에 uploads/ 폴더 static 서빙이 설정되어 있는지 확인.
없으면:
- npm install @nestjs/serve-static (apps/api 폴더에서)
- main.ts 또는 app.module.ts에 ServeStaticModule 설정 추가
- rootPath: join(__dirname, '..', 'uploads') 또는 적절한 경로
- serveRoot: '/uploads'

### Step 7: 프론트엔드 이미지 표시 확인
apps/web/src/app/wardrobe/page.tsx (또는 옷장 관련 컴포넌트)에서:
- 아이템 카드에 imageUrl이 있으면 이미지 표시
- src={`http://localhost:3001${item.imageUrl}`}
- next.config.js에 localhost:3001 이미지 도메인이 허용되어 있는지 확인

## 에러 대응
- 크롤링 차단 시: Playwright로 전환하거나, --count 20으로 소량만 테스트
- 이미지 URL이 깨지는 경우: _normalize_image_url 로직 수정
- Permission 에러: 폴더 권한 확인
- 모든 에러와 해결 과정을 기록

## 작업 완료 후 결과 저장
모든 작업이 끝나면, 프로젝트 루트에 claude_results.txt를 생성/업데이트해줘.

내용에 포함할 항목:

1. 작업 요약 (한 줄)
2. 실행한 명령어 목록
3. 크롤링 결과 (카테고리별 수집 개수, 실패 개수)
4. 수정된 파일 목록 (경로 + 변경 내용)
5. 신규 설치한 패키지
6. 확인 방법
   - API 서버 실행: cd apps/api && npx @nestjs/cli start --watch
   - 이미지 확인: http://localhost:3001/uploads/clothing/{파일명}
   - 프론트 확인: http://localhost:3000/wardrobe
7. 에러 발생 시 해결 과정
8. TODO / 알려진 제한사항
```
