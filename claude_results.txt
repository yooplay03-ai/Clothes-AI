MoodFit 무신사 크롤링 + 연동 전체 구현 결과
작업일시: 2026-03-10
============================================

## 1. 작업 요약
무신사 내부 API 기반 크롤링 스크립트 작성 및 MoodFit API/웹 이미지 연동 완료
(상의/아우터/바지/신발/가방/액세서리 6개 카테고리, 총 500개 목표)

## 2. 생성된 파일
- scripts/crawl_musinsa.py       — 메인 크롤링 스크립트 (MusinsaCrawler 클래스)
- scripts/import_to_moodfit.py   — MoodFit 시드 데이터 변환 스크립트
- scripts/requirements.txt       — Python 패키지 목록
- data/images/{category}/        — 다운로드 이미지 저장 폴더 (gitignore 처리됨)
- data/metadata.json             — 수집 결과 메타데이터 (크롤링 후 생성)
- data/moodfit_seed_items.json   — MoodFit 시드용 JSON (변환 후 생성)
- data/crawl_log.txt             — 실행 로그 (gitignore 처리됨)

## 3. 설치한 패키지
- requests>=2.31.0
- beautifulsoup4>=4.12.0
- Pillow>=10.0.0
- tqdm>=4.66.0

## 4. 실행 방법

# 패키지 설치
pip install -r scripts/requirements.txt

# 전체 크롤링 (기본: 카테고리당 50~100개)
python scripts/crawl_musinsa.py

# 상의만 50개 크롤링
python scripts/crawl_musinsa.py --category top --count 50

# dry-run 테스트 (다운로드 없이 URL 확인)
python scripts/crawl_musinsa.py --dry-run

# MoodFit 시드 데이터 변환
python scripts/import_to_moodfit.py

## API 엔드포인트 (전체)
베이스 URL: http://localhost:3001/api

### 인증 (Auth)
- POST /auth/register — 회원가입
- POST /auth/login    — 로그인 (JWT 발급)
- POST /auth/logout   — 로그아웃
- POST /auth/refresh  — 토큰 갱신
- GET  /auth/me       — 내 정보

### 유저 (Users)
- GET   /users/me         — 내 프로필
- PATCH /users/me         — 프로필 수정
- GET   /users/:username  — 유저 프로필 조회
- POST  /users/:id/follow — 팔로우
- DELETE /users/:id/follow — 언팔로우

### 옷장 (Wardrobe)
- GET    /wardrobe         — 목록 조회 (필터/페이징)
- POST   /wardrobe         — 아이템 추가
- GET    /wardrobe/stats   — 통계
- GET    /wardrobe/:id     — 아이템 상세
- PATCH  /wardrobe/:id     — 아이템 수정
- DELETE /wardrobe/:id     — 아이템 삭제
- POST   /wardrobe/:id/image — 이미지 업로드

### 코디 (Outfits)
- GET  /outfits/recommendations     — 추천 목록
- POST /outfits/recommend           — AI 추천 요청
- GET  /outfits/recommendations/:id — 추천 상세
- POST /outfits/recommendations/:id/save — 저장
- POST /outfits/wear-log            — 착용 기록
- GET  /outfits/wear-log            — 착용 히스토리

### 커뮤니티 (Community)
- GET  /community/feed                        — 피드
- POST /community/posts                       — 게시물 작성
- GET  /community/posts/:id                   — 게시물 상세
- POST /community/posts/:id/like              — 좋아요
- DELETE /community/posts/:id/like            — 좋아요 취소
- GET  /community/posts/:id/comments          — 댓글 목록
- POST /community/posts/:id/comments          — 댓글 작성

### Swagger 문서
http://localhost:3001/api/docs
